# Wireframe du projet

## Mobile
En-tête : logo → liens qui reviennent à la ligne → choix du thème.
Hero : [intro] puis [art] puis [info].
Programme : [heading] puis [day-one] puis [day-two].
Bandeau village indépendant vertical.
Invités : une carte par rangée, puis plusieurs dès que 20rem par carte tiennent.
Billetterie : offres empilées. FAQ puis bandeau étroit. Footer.

## Desktop (48rem et plus)
Hero : [intro | art], puis [info sur les deux colonnes].
Programme : [heading sur deux colonnes], puis [day-one | day-two].
Village indépendant horizontal si son conteneur atteint 35rem.
Invités : grille auto-fit, cinq lignes partagées avec subgrid.
Offres : trois colonnes selon la place disponible.
FAQ : [questions | bandeau], dont le bandeau reste vertical car son conteneur est étroit.

Ce document est une proposition technique ; validation de l’enseignant non obtenue dans cette session.
